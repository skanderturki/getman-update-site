# GetMan update site

Eclipse p2 update site for [GetMan](https://github.com/skanderturki/getman), served by GitHub Pages at
https://skanderturki.github.io/getman-update-site/

In Eclipse: **Help › Install New Software… › Add…** and enter the URL above.

The files here are build output: run `mvn clean verify` in the GetMan repository and copy
`releng/com.getman.site/target/repository/` here.
