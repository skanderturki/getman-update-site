GetMan update site

This is the Eclipse p2 update site for GetMan, a free REST client inside the Eclipse IDE.

From the Eclipse Marketplace

Drag the Install button onto your running Eclipse, or open Help › Eclipse Marketplace…, search for GetMan and click Install. See the Marketplace listing.

From this update site

In Eclipse, open Help › Install New Software…, click Add… and enter:

https://skanderturki.github.io/getman-update-site/

See the user guide for details.
